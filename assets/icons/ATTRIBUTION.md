# Icon attribution

The following UI icons are from Icons8 and are included as bundled assets:

- `quick_snip.png` — Screenshot, Windows 10 style: https://icons8.com/icon/15081/screenshot
- `google_lens.png` — Google Lens, Color style: https://icons8.com/icon/GyA495QxM8El/google-lens

The application recolors these icons at runtime to match the active UI theme.
