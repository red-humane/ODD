## 🌟 Key Features

### 🏝️ Dynamic Island & Bezel HUDs
- **Caps Lock & Audio Mute Squircles**: Smooth animated in-and-out HUD indicators.
- **Live Media Equalizer**: Real-time waveform visualizer and playback controls for Spotify, Apple Music, YouTube, and browser audio sessions.
- **Top Bezel Countdown Notch**: Live countdown ticker embedded inside the screen bezel.
- **Volume HUD Capsule**: Floating capsule showing granular volume levels.
- **Battery & Power States**: Animated charging transitions and battery indicator.

### 🔍 Spotlight Universal Search (`Alt + Space`)
- **Multi-App / Web / File Split-Screen Tiling (New in v3.5)**: Type natural queries for 2, 3, or 4 targets (e.g., `"edge and word"`, `"chatgpt and vs code"`, `"story.pdf, word and vs code"`, or 4 apps) to simultaneously launch and DWM-snap windows side-by-side or into a 2×2 quadrant grid.
- **Native WSearch Indexing**: Instant sub-millisecond local file and folder discovery.
- **Universal Launcher**: Fast launch for Win32 apps, UWP apps, and Control Panel utilities.
- **File Categories & Previews**: Instant grouping into Documents, Media, Code, Archives, and PDFs.
- **Built-in Calculator**: Real-time mathematical expression evaluation in the search bar.
- **Quick Web Prefixes**: Direct routing (`g `, `yt `, `gh `, `r `, `w `).
- **Clipboard & Quick Notes**: Recall recent clips and manage quick notes directly.
